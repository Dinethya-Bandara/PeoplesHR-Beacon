# dateFormat

**Task:** Date Format

**Tags:** All, Headers

**Status:** live

## Description

If the user submits any query related to dates, first execute the "dateFormat" tool to determine the appropriate date format. Then, use the resulting format information (name, description, and example) in the payload of the next tool. Finally, regardless of the format in which the user provides the date, it must be converted into the example format specified.
