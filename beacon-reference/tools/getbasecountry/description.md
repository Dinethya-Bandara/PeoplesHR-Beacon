# getBaseCountry

**Task:** Fetching Base Country Details

**Tags:** EIMAdmin, GeographicalLocations

**Status:** live

## Description

Returns the Base Country from the Country summary grid by detecting the highlighted row (background-color: BurlyWood). Does not open the record.

## Signature

```
getBaseCountry
```

## Arguments

- `mode` (string, optional) — "showAll" (default)
- `fallbackToFirstRow` (string, optional) — "true" or "false" (default "false"). If highlight row not found, optionally return first row.


## Advanced arguments

_None._
